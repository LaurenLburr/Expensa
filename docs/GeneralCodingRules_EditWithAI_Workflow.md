# General Coding Rules Editing Workflow

## After applying this zip

1. Rebuild the solution.
2. Run `CodexExpensa.ExtensionDevHost`.
3. Open:

```text
Docs → General Coding Rules
```

4. Click:

```text
Show Source
```

5. Edit the rules.
6. Click:

```text
AI Review
```

7. Review the AI-updated rendered document.
8. Click:

```text
Save
```

## Important

`AI Review` does not save automatically. This is deliberate so you can review the AI changes before committing them.
