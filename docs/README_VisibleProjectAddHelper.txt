Visible project-add helper

Extract into:

D:\Git

Run:

D:\Git\CodexExpensa\AddCommandEngineProjectsToExtensionsSolution.Visible.cmd

This version:
- opens a visible console window
- pauses before doing anything
- writes a log to your Desktop:
  CodexExpensa_AddCommandEngineProjects.log
- prints manual project-add instructions if it cannot find/edit the solution

Do NOT run as admin unless your repo requires admin access. Running as admin can sometimes change paths/permissions and make things weirder. Windows: helpful like a raccoon with bolt cutters.
