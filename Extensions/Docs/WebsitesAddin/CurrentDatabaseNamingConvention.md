
# Current Database Naming Convention

All active copied databases now use the canonical filename:

```text
current.db
```

Examples:

```text
Extensions\Modules\WebsitesAddin\DevDatabase\current.db
```

```text
%APPDATA%\Expensa\Extensions\Runtime\WebsitesAddin\current.db
```

Archived backups use generated timestamped names such as:

```text
current.before-prod-copy.20260601_142533.db
```
