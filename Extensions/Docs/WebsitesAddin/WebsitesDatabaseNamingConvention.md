
# Websites Database Naming Convention

Active Websites databases now use:

```text
websites.current.db
```

Development example:

```text
Extensions\Modules\WebsitesAddin\DevDatabase\websites.current.db
```

Runtime example:

```text
%APPDATA%\Expensa\Extensions\Runtime\WebsitesAddin\websites.current.db
```

Archived copies use timestamped names:

```text
websites.current.before-prod-copy.20260601_143522.db
```
