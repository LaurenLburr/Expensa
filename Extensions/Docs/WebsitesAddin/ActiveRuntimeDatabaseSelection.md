# Active Runtime Database Selection

Copied databases can now be selected and activated as the current runtime database.

## Workflow

1. Copy a database from:
   - dev template
   - Sandbox DB

2. Select the copied database in the list.

3. Click:

```text
Make Active
```

The active runtime database path is stored in:

```text
%APPDATA%\Expensa\Extensions\Runtime\WebsitesAddin\active-runtime-db.txt
```
