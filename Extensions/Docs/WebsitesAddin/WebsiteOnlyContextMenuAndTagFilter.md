# Website-Only Context Menu and Tag Filter

## Tree behavior

```text
Category Group
    Website node
```

The category/tag group node does not show a context menu.

The website node shows the context menu.

## Website node selection

Selecting a website node is the place to load the website details page.

Right-clicking a website node is the place to assign tags.

## Tag picker

The underscore menu opens a full-height tag picker next to the tree.

The list excludes tags already assigned to the selected website.

Duplicate assignments are still protected at the database layer by checking for an active existing assignment before inserting.
