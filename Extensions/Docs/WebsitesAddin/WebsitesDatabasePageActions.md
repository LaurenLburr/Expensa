# Websites Database Page Actions

The Websites Database page includes an add-in database control section.

## Runtime database label

The database name is clickable.

Clicking it opens the folder containing the runtime database.

```text
%APPDATA%\Expensa\Extensions\Runtime\WebsitesAddin
```

## Copy actions

The page provides two links:

```text
Copy new from dev template
Copy new from Sandbox DB
```

Copied databases use generated timestamped names, so the UI does not need to search for or ask for a name.
