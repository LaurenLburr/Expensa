# Websites Tree Context Tag Assignment

The underscore tag picker now assigns tags to the selected website node.

## Typed tag behavior

When the user types a tag and presses Enter:

```text
Tag
TagAssignment
```

are updated.

If the tag does not exist, it is created first.

## Existing tag behavior

When the user double-clicks a tag in the list:

```text
TagAssignment
```

is created for the selected website.

## Important

The user must select or right-click an individual website node before assigning a tag.

Assigning a tag to a tag/root node is blocked.
