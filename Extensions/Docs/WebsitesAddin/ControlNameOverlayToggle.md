# Control Name Overlay Toggle

The Websites Database form now has a tiny `?` button in the upper-right corner.

Clicking it toggles display of control names for controls with visible UI text.

Examples:

```text
Refresh  [refreshButton]
Search:  [searchLabel]
Add-in Database  [databaseGroupBox]
```

Text boxes, grids, numeric controls, and list views are skipped so data does not get overwritten.
