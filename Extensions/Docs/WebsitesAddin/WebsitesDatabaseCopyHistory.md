# Websites Database Copy History

The Websites Database page now shows copied database files created during the current session.

## Behavior

- Copy from dev template creates a timestamped database file.
- Copy from Sandbox DB creates a timestamped database file.
- The copied file is added to a list.
- Selecting a copied database shows its full path.
- Open copied DB folder opens the containing folder.

This is a UI convenience only. It does not yet switch the active runtime database.
