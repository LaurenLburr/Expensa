# Websites Tree Context Menu Tag Picker

The Websites tree context menu now includes a menu item labeled only with underscores:

```text
________
```

Clicking it embeds a tag picker inside the context menu.

## Behavior

- The picker contains a text box and list box.
- The list box filters tag names as the user types.
- Tag names come from the current root tree nodes.
- Pressing Enter or double-clicking a tag selects the matching tag node.
- The selected tag node is brought into view.
