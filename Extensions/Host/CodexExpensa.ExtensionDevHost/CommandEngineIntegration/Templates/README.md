# CommandEngineIntegration Templates

This folder is for manually designed WinForms template forms that are reused by the Extension Dev Host integration screens.

## Current templates

- `DatabasePanelTemplate` - base form/layout for add-in database panels.
- `TreeTestTemplate` - base form/layout for add-in tree test pages.

These templates are project/UI organization only. They do not change the database schema, SQL catalog, runtime database files, or add-in data.
