Adds the first conversational AI design workspace.

## Features

- Saved AI design sessions
- Conversation pane
- User message box
- Editable Add-in Design Spec
- Editable Expensa Integration Spec
- Export docs into `Extensions/Modules/[ProjectName]/Docs/`

This does not generate code yet. It is the design conversation foundation.
